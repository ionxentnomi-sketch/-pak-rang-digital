Pak Rang Digital — موبائل ویب ایپ

یہ ایک ابتدائی Progressive Web App (PWA) ہے جس میں:
- لائیو یوٹیوب صفحہ
- یوٹیوب ویڈیوز اور شارٹس
- چینل لنک
- شیئر بٹن
- موبائل فرینڈلی گرین/وائٹ ڈیزائن

اہم: یہ فائلیں ابھی آن لائن شائع نہیں ہوئیں، اس لیے ابھی عوام کو دینے کے لیے ویب ایپ کا اپنا لنک موجود نہیں۔ اسے HTTPS hosting پر اپلوڈ کرنا ہوگا (مثلاً GitHub Pages یا کسی دوسری hosting سروس پر)۔ اپلوڈ کے بعد لوگ لنک کھول کر Chrome کے مینو سے Add to Home screen / Install app کر سکتے ہیں۔ یہ APK نہیں بلکہ انسٹال ہونے والی ویب ایپ ہے۔
